# 品记项目提案 · 产品截图版

双击 **品记-项目提案.html** 可离线阅读。图片、样式、脚本及依据文档全部内嵌。页首支持打印；页尾可以展开来源并下载文档。

沿用简明版的短句、案例和价值点。品单、版本比较、邀请与答案分享均改为真实应用截图或实际导出的 PNG，支持展开查看。两幅生活场景插图保留 AI 标注。

## 维护

- `index.html`：正文和结构。
- `pitch.css`：桌面、窄屏、打印与减少动效样式。
- `pitch.js`：截图切换、原尺寸查看与打印。
- `assets/`：6 张界面截图、2 张实际导出图、2 幅场景插图、应用图标及来源记录。
- `DESIGN.md`、`.impeccable/design.json`：视觉约定。
- `SCREENSHOT_VALIDATION.md`：当前截图版验收；`VALIDATION.md` 保留简明版记录。

修改后，在项目根目录运行 `node scripts/package-pitch.mjs` 重新打包。浏览器检查使用 `scripts/qa-pitch.js`，本地静态预览端口为 5180。

## 内容边界

界面直接拍摄自当前代码的显式开发预览，载入“范例1”的 53 篇笔记与 65 份版本；没有改写原资料库、重绘界面或修改截图中的文字。分享图由应用的“保存全部图片”操作实际导出。截图是当前前端界面实拍，不冒称 Windows 安装包截图。

范例人物、经历和交流为虚构，不是用户反馈。长期自我理解和关系价值仍待验证。应用能力以项目 PRD 和代码为准。

截图来源、窗口尺寸、区域和原始字号记录在 `assets/manifest.json`。窄屏使用应用窄窗口截图；分享导出图以保证最低 18px 的尺寸显示，可横向滚动。展开后按原像素查看；打印使用可读的窄图与导出图。

第一版备份及制作规划位于 `output/pitch-authoring/`，不进入交付 HTML。
