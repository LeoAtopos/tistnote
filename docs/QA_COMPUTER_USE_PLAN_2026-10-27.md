# 品记全面功能摸排计划

编制时间：2026-10-27。要求：先形成计划，再逐项使用 Computer Use 操作实际界面；结果记录在同目录的 `QA_COMPUTER_USE_REPORT_2026-10-27.md`。

## 目标与执行方式

- 对照需求和当前界面摸排可见功能，关注无法完成操作、内容丢失、错误状态、历史 / 回顾失真、交互与布局问题。
- 主测 Windows 本地应用的真实资料库；浏览器开发预览补测尚未进入发布包的“编辑时隐藏品交”。网页版能安全访问时补测，移动系统专属行为区分实际设备与可检查范围。
- 所有界面输入、点击、拖拽、滚动和键盘操作使用 Computer Use。可以读取测试目录验证输出文件、编写报告；不调用应用内部 API、不注入 DOM / 存储数据代替界面测试，不把既有自动化通过当成本轮操作通过。
- 使用独立测试资料库与测试内容，绝不改动 `example/`、用户当前资料库及已有笔记。保留导出、备份和测试数据供复核；不上传、不发送分享图片，不发布或重新打包。
- 遇到系统权限、安全或安装提示时不代为同意；记录受限项目。删除类操作按 Computer Use 规则在动作前单独处理，只针对新建测试数据。没有实际执行的项目标为未测 / 受限，不能标为通过。
- 先检查正常主流程，再检查边界与失败恢复。发现问题先记录复现步骤、预期、实际、影响和证据，不擅自扩大为代码修复任务。

## 完成标准

每项都有状态；失败项可复现并说明影响；受限项说明未完成的原因与替代证据，不能以源码推测代替实测。最终报告给出覆盖率、问题清单、证据索引和建议处理顺序。计划可根据实际发现补充子用例，但不删除失败或受限项目。
