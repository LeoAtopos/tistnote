# 品记功能全景图

打开 [品记-功能全景图.html](品记-功能全景图.html)。图片、数据、样式和脚本已内嵌，可复制到其他位置离线阅读。

6 个分支、36 项功能、40 张图片：38 张当前应用界面截图，2 张应用实际导出 PNG。

点击脑图节点看功能，也可以按顺序浏览。每项有简短价值说明、操作入口、人物范例和实际截图。支持搜索、分支展开与收起、截图切换、原图保存和直接链接。窄屏保持层级，截图原尺寸滚动，不缩小字号。

## 内容来源

使用虚构的范例1：林知夏，23 岁，北京；53 篇笔记，26 篇非模板主题，27 / 45 个内置主题已填写，覆盖率 60%。截图取自当前代码的显式 `?preview` 开发预览，截图日期 2026-10-25。

新建、排序、填写日志、回顾、回收站及冲突为隔离预览副本中的实际操作。原范例资料库与应用代码没有因此修改。开发预览不是正式本地存储。

本地文件管理器、备份、恢复和导入只展示设置入口；预览中这些操作呈禁用状态，没有伪造 Windows 系统对话框。相关功能说明依据当前 PRD 和代码。

## 维护

- `index.html`、`map.css`、`map.js`：页面结构、视觉与交互。
- `features.json`：功能分支、顺序、说明与截图对应关系。
- `assets/`：原始截图及 `manifest.json`，保存尺寸、来源、日期和字号下限。
- `data.js` 与单文件 HTML：由 `node scripts/package-product-map.mjs` 生成。
- `scripts/qa-product-map.js`：在独立浏览器中检查全部功能，不操作正式应用。

打包脚本检查功能唯一性、脑图顺序、图片有效性和完整覆盖。验证范围见 [VALIDATION.md](VALIDATION.md)。现有项目提案未改动。
