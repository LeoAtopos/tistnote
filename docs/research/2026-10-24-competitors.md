# 品记 tistnote：竞品资料与产品机会分析

调研日期：2026-10-24（Asia/Shanghai）。项目依据：本仓库 `docs/PRD.md`、`README.md`，其中 PRD 是需求基线，不能视为全部功能已经实测通过。此次仅新增研究资料。

同日方向校正：用户确认以沉心梳理、郑重书写与重要经历后的正式修订为核心；下文产品建议按此调整。竞品数据仍保留原采集口径，品记不以首次录入速度或高频记录作为核心比较目标。

**核心判断：品记处于偏好排名工具、私人反思工具与本地笔记工具的交叉处。最需要比较的是 TierMaker、Listography、Listy 和 Obsidian；Sofa、Sequel 是收藏与消费管理的体验参照；豆瓣、Letterboxd、Beli 是品味表达与交流的行为参照。**

## 资料口径

- 覆盖 13 款产品。优先使用官方网站、官方商店、官方帮助和创作者自述；未安装并逐一实测这些应用。
- 附件 `2026-10-24-app-store-snapshot.json` 保存 Apple 公开 Lookup API 的 10 款应用事实字段，含查询 URL、商店地区、评分、评分人数、版本与日期。其余 3 款为 Listography、Obsidian、Notion，本次未采集其商店数据。
- 美国区与中国区分开呈现；评分人数是特定地区的累计评分，不是下载量、月活、付费人数或全球用户数。商店界面的四舍五入数字可能与 API 略有不同。
- App Store 首发日期仅对应当前 app ID；最新版本日期仅对应该商店记录。网页产品、Android 或历史旧版可能有不同时间线。较久未更新不能直接推出停运。
- 价格按网页或商店显示币种记录，不做汇率换算。内购列表可能包含旧商品、促销与不同周期；周期不明确的项目不自行补全。下载免费也不等于所有功能免费。
- “未披露”表示本次未找到可验证公开数据。“未见主打”表示查阅资料没有将其列为核心，不能等同于确认不存在。
- 研究解释、竞品优先级、产品建议与实验阈值属于本报告判断，不是厂商披露或市场统计。

## 品记实际争夺的使用场景

按当前 PRD，品记首版是 Windows 10/11 x64 应用，完全离线、无账号与云服务，文件以 Markdown 保存在本地。核心工作是：围绕自选主题，列出好恶、理由与可选排名，回看条目和理由的变化，再按公开范围生成答案图或不含自己答案的邀请图。

因此，应分别观察四种替代行为：

| 用户此刻想做的事 | 最可能使用的替代物 | 品记要证明的额外价值 |
| --- | --- | --- |
| 做一张“我的最喜欢/最讨厌”排名图 | TierMaker、Lomo、手工排版与截图 | 文字理由清晰、编辑省事、能保留并回看变化 |
| 写出关于自己的主题列表 | Listography、普通日记、flomo | 从问题开始填写，列表结构明确，允许矛盾和未定感受 |
| 保存书影音偏好 | Listy、Sofa、Sequel、豆瓣、Letterboxd | 不限媒介和数据库条目，重点在个人判断及理由 |
| 长期保管私人笔记 | Obsidian、Notion、普通 Markdown | 无需搭建模板和插件即可完成排名、版本比较与图片交换 |

## 关键发现与证据

### 1. “用列表认识自己”已有长期参照，不能当作尚未有人做过

[Listography 官方关于页](https://listography.com/listography)称网站于 2006 年上线，强调用列表形成自传、生活地图与时间胶囊，允许自传性主题、愿望、推荐和日常列表，并有主题生成入口。官网还将购买纸本日记作为支持方式。

这说明这个表达形式有长期存在的受众，但公开资料不足以判断它的活跃规模或盈利。对品记而言，它是内容与场景上的高优先级参照。品记能够争取的差别是本地文件、明确的条目理由、偏好变化比较，以及选择字段后的图片交换；这些是具体流程差别，不能宣称全球独有。

### 2. Listy 与品记的叙事距离比“收藏工具”这个标签更近

Listy 在 [2026-03 的官方文章](https://listy.is/blog/2026/03/20/listy-app-build-your-identity-through-lists/)中已将列表描述为身份、个人档案与品味变化，并强调私密。这只能证明其定位表述，不能证明用户主要为这一点使用或付费。

品记不应仅靠“审美”“认识自己”两组词区分。更可检查的差异是：主题不依赖媒体数据库，条目可包含观念和关系，保留负向与未定感受，并以条目身份比较排名和理由的变化。Listy 的强项是内容检索和元数据；在完全离线边界下，品记应检验纯文字结构和主题引导是否更适合集中梳理、仔细书写与正式修订，而非以收藏对象的录入速度竞争。

### 3. 排名分享可以吸引尝试，但免费替代与付费阻力明显

[TierMaker 官方](https://tiermaker.com/blog/support/17/creating-an-account-on-tiermaker-with-twitter)说明：已有模板可以免登录制作并下载图片，创建公开模板或保存到个人页才需要登录；官方称有超过 200 万模板。模板量不等于用户量。[App 的付费差别](https://tiermaker.com/app/)集中在无广告、无水印、较高导出质量和移动体验等。

[商店评论样本](https://apps.apple.com/us/app/tiermaker-com/id6744654563?platform=iphone&see-all=reviews)对“网站免费而 App 要付费”有反感，也有支持买断的声音。不能从展示评论计算反感用户比例，但它提示了一项具体风险：用户只想临时生成一张图时，额外安装与付费都容易被拒绝。[Lomo 当前描述](https://apps.apple.com/us/app/tier-list-maker-lomo/id6446122114)还提供了免费、无广告的替代参照。

对品记的启发：分享图要产生即刻价值；长期保留与再次修改的价值应在用户付费前可见。首次收到邀请图的人不一定愿意安装 Windows 应用，这个转化需要验证。

### 4. 小众工具可以获得付费，但媒体曝光不等于足以全职经营

[Sequel 创作者的 2023 年回顾](https://romainlefebvre.com/2024/01/02/sequel-year-in.html)披露：订阅者从年初约 30 人增加到写作时超过 1,500 人；一个自然流量阶段每天约 3 个新试用；“首次打开 → 开始试用”从约 3.5% 到约 7%。作者也提醒来源与流量规模影响比较，不能确认全部提升来自设计变化。

这些是历史自述，不是 2026 年订阅人数、月活或净收入；试用启动率也不是最终付款率。它的价值在于明确了应追踪的行为：首次使用、有效记录、试用、付款和续费。品记不能从竞品高评分或获奖直接推算收入。

### 5. 通用笔记的压力很强，完全本地并不足以构成独立优势

[Obsidian](https://obsidian.md/)本身就在私人笔记与 Windows 端形成替代，[定价](https://obsidian.md/pricing)为核心应用免费、同步等服务可选付费。品记面对的比较会是“为何不在已有笔记里写一个有序列表”。

同时，[Notion 已支持所有套餐在桌面/移动应用中使用离线页面](https://www.notion.com/help/use-pages-offline)。页面需要下载，数据库目前涉及首视图前 50 行等限制；这与品记从首次使用开始不依赖网络、以本地文件为数据基础的设计不同。不能再用“Notion 完全不能离线”作为卖点。

品记应该展示无需配置的完整动作：选题 → 列条目 → 写理由 → 调整顺序 → 回看差异 → 生成清晰图片。通用工具能写同样的内容，但是否能同样省事完成这条流程，需要实际对比任务来判断。

### 6. 引导、回看和朋友交流比单纯存档更值得观察

[Day One 的计划表](https://dayoneapp.com/plans/)把提示问题、模板与往年今日放入基础体验；[flomo 当前会员说明](https://help.flomoapp.com/membership/pro.html)强调回顾、相关笔记和洞察。这说明“让旧记录再次产生价值”已是相邻产品的竞争焦点，并不意味着品记需要引入 AI 或云服务。

[Beli 商店说明](https://apps.apple.com/us/app/beli/id1478375386)将餐厅排名、个人备注、口味档案和朋友匹配放在一起。它的一些评论也反映出不同价位、不同体验之间难以强行比较。这支持品记保留无排名模式和自定主题的产品选择；不支持将所有人生体验放入同一个统一分数。

[豆瓣的近期版本记录](https://apps.apple.com/cn/app/%E8%B1%86%E7%93%A3/id907002334)已覆盖书影音以外的地点、游戏和生活记录；[Letterboxd](https://letterboxd.com/faq/)则提供电影日记、列表与交流。品记要争取的是特定的私人整理与熟人交换时刻，不需要把用户已有的公共档案全部替换掉。

## 与当前 PRD 的能力对照

“核心”指资料明确主打；“可实现”指通用记录可表达，未确认有专门流程；“未确认”不等于没有。这里只比较已查证方向，不做百分制功能评分。

| 比较维度 | 品记（PRD 目标） | TierMaker | Listography | Listy / Sofa / Sequel | Obsidian / Notion | Day One / flomo |
| --- | --- | --- | --- | --- | --- | --- |
| 任意主题、纯文字判断 | 核心 | 以图像分档为主 | 核心 | 可自定义，重心为内容收藏 | 可实现 | 可实现 |
| 条目理由与有序/无序表达 | 独立理由字段，排名可切换 | 分档排序为主，理由流程未确认 | 自由文本可表达 | 备注与手动组织，形式各异 | 可实现，需自建约定 | 自由文本可表达 |
| 同一主题前后排名、理由的语义比较 | 明确设计 | 未确认 | 未确认 | 未确认 | 有历史/扩展能力；专门语义比较未确认 | 有历史/回看；专门语义比较未确认 |
| 不带自己答案的邀请图 | 明确设计 | 可复用模板；传播方式不同 | 主题与公开列表；流程不同 | 有分享能力；对应邀请流程未确认 | 可手工制作 | 对应流程未确认 |
| 无账号且完全离线的本地资料库 | 明确约束 | 官网流程依赖网络 | Web 服务 | 本地与同步方式各异，元数据搜索需要网络 | Obsidian 最接近；Notion 为下载页面离线 | 隐私机制与多端服务各异 |

品记的有利位置是这些能力的组合及其易用程度。版本机制本身不是护城河；用户是否有足够多值得再次打开和修改的主题，才决定历史比较能否成为持续价值。

## 产品与商业建议（待验证）

### 优先验证三个价值承诺

1. **支持一次值得投入时间的认真梳理。** 选择贴近生活的问题，给用户半小时、一小时或按本人需要更长的空间，观察回想、比较、改写和停顿是否自然，结束后是否留下愿意保留与重读的判断。不要求写满时长、完整 TOP 10 或每条都有理由，不以首条录入速度和条目数量代替价值判断。
2. **回看变化值得回来。** 用户再次打开同一主题时，是否真的调整顺序、补理由或标记不同看法。文件版本比较是能力；看见自己观点变化才是体验。
3. **交换图片能引出交流。** 接收者是否读得懂、愿意回应；以手写、聊天文字回应也算交流价值。另行记录对方是否愿意安装品记，避免把回应率混成安装转化率。

### 保持边界，把缺点讲清楚

- 完全离线、Markdown 和无账号有利于所有权及降低服务依赖；也使首次安装、数据迁移和跨设备记录需要用户自行处理。不能只写优点。
- Windows 适合较长理由、排序和整理；与手机上即时收到推荐、在聊天里填写答案的场景存在摩擦。先验证核心 Windows 用户，不因竞品有手机端就自动扩范围。
- 当前只导入品记格式 Markdown，而非任意 Markdown 自动转换。不能对外宣传“已有 Markdown 可一键迁入”。
- 图片容易跨平台发送，但不能自动恢复结构化主题、追踪回应或连接关系。不要把这一机制的商业前景建立在尚不存在的网络效应上。
- 模板覆盖率与活跃图展示记录数量；是否帮助用户理解自己，需要另问。它们也可能给部分用户带来完成压力。

### 定价与可持续性

竞品覆盖免费、订阅和买断，且价差很大。它们销售的服务不同：Sofa 的计划、进度与播放器，Letterboxd 的统计和社区体验，Obsidian 的同步，以及纯本地品记并不能直接按同一价目比较。

在不改变当前离线边界的前提下，**完整试用后买断或按大版本升级收费，是值得测试的候选**。它与一次下载、长期本地持有的预期较一致；这不是用户已经表现出支付意愿的结论。基础读取、数据导出与备份不宜成为迫使用户付费才能拿回内容的手段。

定价研究先问用户为什么需要独立应用、过去为哪些相近工具付过钱，再测试价格和成交；不要直接拿国外订阅价换算人民币。若用户只需要偶尔生成排名图，应接受它更接近低频免费工具的结果。

本次没有得到品记可用的付费转化率、客单价、可触达人群或获客成本，因此不计算收入预测或 TAM。

## 下一轮建议：小规模、可离线执行的研究

以下为建议方案，尚未进行，也未修改 PRD 或添加遥测。

| 要验证的假设 | 建议方法 | 观察内容 | 可能的反证 |
| --- | --- | --- | --- |
| 有明确使用对象 | 找 8–12 名 Windows 用户，覆盖排名分享、私人日记、本地笔记三类习惯 | 最近一次真实记录、工具、触发与成本 | 只有“听起来不错”，说不出真实场景 |
| 比通用笔记更适合集中梳理 | 同一主题分别用现有工具与品记认真书写，交替试用顺序并留足思考时间 | 思路是否被打断、能否反复斟酌与重读、结果是否愿意保留 | 原有笔记更适合深入表达，品记的结构反而增加干扰 |
| 理由和历史有复访价值 | 自愿试用两周，访谈由用户自己回顾本地记录 | 是否主动回来、改了什么、历史是否有用 | 只有第一次填题，没有主动复访 |
| 图片交换能带来交流 | 用户自行选择是否把图发给熟人，研究者不代发 | 是否回应、以什么形式、是否需要下载安装 | 愿意看图，但不愿安装或另写列表 |
| 有独立付费价值 | 在体验后了解购买选择与替代成本；后续再做真实付费实验 | 购买理由、拒绝原因、可接受收费方式 | 只愿为图案/新鲜感付很低的一次费用 |

研究数据可由受试者同意后口述、问卷或本地日志自愿提供，不需要在正式应用添加联网分析。样本小、招募偏差大，只用于发现问题与修正方向，不外推整体市场占比。

## 数据缺口与更新方式

- 13 款产品的当前付费人数、留存、获客成本和净利润基本不可得；Sequel 的披露只是 2023 年历史样本。
- 本次没有统一可信的活跃用户口径，不使用下载量、模板量和评分量拼接“规模排行榜”。
- 尚未实际完成各应用的同题任务测试，不能将本报告的资料比较当成最终 UX 结论。
- 未验证中国 Windows 用户愿意为品味记录单独安装应用和付费；这是比补更多功能更优先的商业问题。
- 后续如需更新，按 JSON 中的 Apple 查询 URL 再取相同地区数据，并分别记录新日期；价格、平台和隐私边界仍应回到对应官方页面核对。
