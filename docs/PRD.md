## 1. 产品定位

品记（tistnote，taste list note）是一款完全离线、以列表记录个人审美与偏好的笔记应用。核心定位是品察世间万物与人生百态：喜欢、欣赏、认同，以及不喜欢、讨厌、反感与分歧都可以记录，也容纳复杂、矛盾和尚未确定的感受。每一份列表都可以留下个人的感受、判断及其缘由。

品记以类似日记的郑重书写为核心：用户为自己留出一段相对完整的时间，围绕一个主题回顾经历，仔细斟酌条目、理由与取舍，形成值得保存和重读的品单。典型会话可以持续半小时、一小时或更久；这描述产品应支持的思考深度，不是最低使用时长，也不要求每次写满条目或长篇理由。产品不以随时随地快速记一笔、碎片捕捉、高频打开或连续打卡为主要设计目标。

随着技术发展，人的价值将越来越多地体现在独特的感受、选择、表达与创造之中。审美既存在于电影、文学和哲学，也存在于旅行、饮食、牙刷等日常选择。品记把对世间人生的观察、好恶与思考，变成可以积累、回看与交流的记录。

核心价值：用列表认识自己，用变化理解自己，用分享认识彼此。

自我建设与品单社交的成立理论、研究依据及待验证假设见[产品理论](PRODUCT_THEORY.md)。该文档用于解释和验证需求，不新增首版功能承诺。

核心问题：我喜欢什么、讨厌什么，认同什么、反感什么，为什么；如何表达和排列自己的感受与判断；我的审美与偏好如何变化；我希望别人了解我的什么，又希望了解对方什么。

首版面向品察日常与人生、梳理个人好恶、记录审美与偏好变化、与朋友交流感受的人群。采用 Tauri 开发 Windows 10/11 x64 版本，控制包体。

核心使用场景：

1. **主动留出时间梳理自己。** 用户有意识地坐下来，选择一个值得品察的主题，用半小时、一小时或更久回想、比较、书写与反复修改；可以暂存未定判断，下次继续。桌面端的大屏阅读、键盘书写与并置回看服务于这一过程。
2. **重要经历后的正式更新。** 生活中发生某件事、重遇某个对象或产生强烈感受后，用户主动打开相关品单，重读过去的看法，郑重增补、改写理由或调整排名，保留这次理解变化。正式更新是有意识地进入编辑、审视并完成本次修订的使用方式，不新增强制仪式、审批或必须填写的总结字段。

设计原则是减少操作打断，把时间留给思考。界面和流程应直接、稳定，不能为了营造郑重感而增加倒计时、时长门槛、复杂开场或强制完成步骤；也不以尽快写完、生成更多笔记或填满模板来判断使用质量。

全部笔记、模板、历史、图片生成均在本地完成。没有账号、服务器、云同步、在线模板库、信息流、社交关系、广告、遥测、联网分析或联网更新。分享仅生成图片，不生成可浏览的笔记链接。导出和备份属于数据管理。

## 2. 数据与流程

笔记由主题、可选说明、多个标签、排名模式、条目、时间与版本历史组成。条目包含名称、可选理由和稳定身份。模板来源可记录，但笔记创建后独立于模板。

有排名与无排名随时切换，保留条目与顺序；无排名的顺序仅表示展示位置。首版使用纯文字，不包含图片条目、星级评分、嵌套列表、复杂表格或富文本。

主流程：

1. 留出梳理时间 → 新建或从模板确认主题 → 回顾经历、反复填写、比较取舍与补充理由 → 持续自动保存 → 完成本次编辑，之后可重读或继续。
2. 浏览、搜索或按标签随机抽取模板 → 确认主题 → 创建笔记。
3. 打开历史 → 比较两个版本 → 按需恢复。
4. 分享 → 选择条目与公开字段 → 预览 → 保存 PNG → 用户自行发送。
5. 求品 → 确认主题与邀请语 → 保存图片 → 对方自行填写同主题列表并以图片回应。
6. 重要经历或强烈感受触发 → 打开相关品单并重读 → 进入编辑，正式增补或修订 → 完成编辑并保留版本 → 按需比较前后变化、命名里程碑或分享。

应用不追踪邀请发送、填写或回应，不记录收件人身份。

- 2026-10-26 笔记画布：默认保留列表视图，在“我的笔记”的更多菜单选择“画布视图”。以“品记”为中心，按实际分组及子分组递归展开，未分组笔记直接连接中心，空分组也保留。空心圆表示没有有效条目的笔记，实心绿圆表示已有内容；仅有内容且已过回顾周期的圆点右上角再显示小绿点。到期状态自动刷新，确认回顾后同步更新。悬浮或键盘聚焦显示标题，点击进入原笔记浏览 / 编辑界面，可返回原位置与缩放的画布；支持搜索、标签筛选、平移、滚轮 / 双指缩放、缩放按钮及居中，文字字号不随缩放改变，可随时切回列表。视图不改变资料库文件结构。

模板包含主题、可选说明与填写提示、标签、默认排名模式、建议条目数。建议数量不限制填写数量。

模板用于邀请用户认真品察一个问题，提示应支持回想具体经历、辨认理由与比较取舍，避免“几秒填完”“赶快打卡”等催促。允许少量条目、暂时没有理由、未定感受和分多次完成；随机抽题帮助找到值得投入时间的主题，不以连续换题或覆盖全部模板为目标。覆盖率仅表示已有记录范围，不代表自我建设程度。

首版提供约 45 个内置主题，覆盖电影、文学、音乐、旅行、饮食、生活用品、思想与哲学、休闲、设计及人与关系。内置主题兼顾喜欢与欣赏、不喜欢与反感，以及复杂和未定的感受。原有主题 ID 保持稳定，补充的负向与中性主题追加在目录末尾。内置模板不可直接修改，可以复制后编辑。

2026-10-26 模板库默认采用分支画布：模板库 → 标签 → 模板。多标签模板在各标签下展示，无标签模板归入“未分类”；空心圆表示模板，实心绿圆表示已有“有品”笔记，沿用覆盖率判定。支持拖拽平移、滚轮与双指缩放、缩放按钮及居中；缩放仅改变图形位置，文字字号不随画布缩小。悬浮或键盘聚焦圆点显示标题，点击或 Enter 展示原模板卡片，点击空白或 Escape 关闭。卡片中的填写、查看、复制编辑和个人模板管理功能保留。搜索和标签筛选作用于画布，也保留卡片视图。

用户可以新建、编辑、复制、删除个人模板，也可以从笔记提取主题、说明、标签与模式。提取时不复制答案和理由，保存前展示可编辑预览。

2026-10-24 模板覆盖率：模板卡片与随机抽到的主题在已有对应品记时显示“有品”，侧栏“模板库”旁显示整个模板库的覆盖百分比，页面显示有品数量 / 模板总数。范围包括内置及个人模板，搜索和标签筛选不改变总分母；同一模板最多计一次，百分比保留一位小数。对应品记按模板来源 ID 或标题完全一致（忽略首尾空白）识别，须有有效主题及至少一个非空条目；空笔记、空白条目和回收站笔记不计入。带来源的笔记改名后仍保留关联，清空 / 删除 / 恢复后按在用笔记实时更新；覆盖状态由已有数据计算，不新增追踪日志。

随机抽取遵循当前搜索和标签条件，多个候选时不连续重复；换题不会创建笔记，只有点击“开始填写”才创建。模板后续修改和删除不影响既有笔记。标签清理首尾空白并去重。

2026-10-25 模板与笔记联动：已“有品”的模板，其标题、“有品”标记及“查看笔记”操作直接打开对应在用笔记，主导航切换到“笔记”，以浏览状态显示正文；随机抽题中的已覆盖模板同样处理。匹配沿用模板来源 ID 或标题完全一致（忽略首尾空白），只选择有有效主题和条目的在用笔记；多个匹配时打开最近更新的一篇。跳转清除模板搜索与标签筛选，避免隐藏已打开的笔记。不自动创建副本；仍可从模板的更多菜单选择“另写一份”。未覆盖模板保留“开始填写”流程。

## 4. 版本日志

2026-10-24 新增使用历史：侧栏在“模板库”下方提供独立“历史”入口，以类似 GitHub contribution graph 的年度日期网格展示新增与修改活跃度。支持切换年份、选择日期、键盘方向键导航、查看当天记录及打开仍在用的笔记。窄屏图表内部横向滚动，不缩小文字。创建按笔记创建时间统计，修改按保存版本的实际内容变化及修改时间汇总；同一天同一篇笔记的多次修改合并计一次。未改内容的里程碑、重复打开和刷新不增加次数，跨天才首次填写空白笔记会计入填写当天的修改。

汇总完全读取本地现有笔记、回收站和版本文件，不联网，不单独追踪使用行为，不改写原文件。早期记录以已保留版本为准，无法还原未保存成版本的中间编辑；永久删除笔记及其历史后，其记录也从使用历史移除。原有单篇笔记版本比较与恢复仍保留在笔记界面。

自动保存与版本记录独立：前者保护当前内容，后者形成可阅读的时间线。

编辑工具栏提供“取消编辑”。未更新时直接返回浏览，不生成提交；内容、回顾周期或所在分组有更新时，弹窗说明退出将丢失本次更新，提供“继续编辑”和“放弃更新”。确认放弃后恢复进入编辑时的内容、回顾周期、分组及原更新时间，即使内容已自动保存也可恢复；等待正在进行的保存结束，防止待执行的自动保存回写已放弃内容。恢复前检查修订冲突、标题唯一性及原分组是否可用，失败时保留编辑状态和已有文件。已生成的自动历史和里程碑保留，取消本身不追加提交记录。

版本日志服务于重读和理解一次认真修订中的判断变化。自动版本保留书写过程；每次点击“完成编辑”时填写更新日志，提交后生成附带日志的版本并返回浏览状态，取消则继续编辑。日志可留空，支持多行；即使内容已被自动版本留存，本次提交仍单独保留。提交失败保留日志和编辑状态，提交前检查修订冲突。日志可在单篇笔记历史中查看。用户仍可按需为重要经历或重新理解命名里程碑。自动保存不应让用户反复担心是否已经保存，“完成编辑”表示结束本次书写，不表示这份品单已经定稿或必须立即分享。

使用历史用于回找何时认真梳理过哪些主题，允许两次使用之间有较长间隔；不增加连续打卡、目标写作时长、断更惩罚或成长分数。有效使用关注用户是否留下值得重读的判断、能否理解变化，不以活跃天数、编辑次数或时长衡量深度。

- 首次有效内容创建初始版本。
- 有修改且停止编辑 60 秒后生成自动版本。
- 离开笔记或正常关闭应用时补存尚未记录的内容。
- 相同内容不重复创建自动版本。
- 手动里程碑可以命名；首版不自动清理历史。
- 时间线显示时间、类型、名称和变化摘要。
- 默认比较所选版本与前一版本，也支持任选两个版本。
- 比较条目增删、改名、理由、位置 / 排名及主题、说明、标签和模式。
- 稳定条目标识避免将改名误判为增删；标识丢失时明确提示精度下降。
- 恢复前留存当前内容，恢复形成新版本，不修改旧历史。
- 异常退出后以最后成功保存内容恢复；重新打开时补记遗漏版本。

### 回顾提醒与确认

每篇笔记默认回顾周期为 3 个日历月，编辑界面可选择 1、2、3、6、12 或 24 个月，以及明确标注的“1 分钟（测试）”。测试选项按 60 秒计算，确认后重新计时，可随时切回月周期；不会改变默认 3 个月。以创建、内容更新、上次回顾确认中最晚的时间起算；月末按目标月份最后一天对齐，到期后在列表标题同行显示绿点，提示“需要回顾”。页面停留期间每分钟检查；有品单启用一分钟测试时每秒检查，重新打开和回到应用时重新计算，不依赖网络或常驻后台。

浏览工具栏提供“回顾确认”，未到期也可使用。确认后保留当下时间并重新计算下一次回顾时间，内容页以上次“2分钟前”、下次“3天后”、到期“已过1小时”等相对时间简洁展示，悬停可查看完整日期时间；每次确认生成独立的“回顾确认”历史记录，保留确认时间和当时的品单；不改动内容更新时间。年度历史图单独统计回顾，与新增和内容修改区分，同一天同一篇品单的多次确认合并计一次，单篇历史仍保留每一次确认。确认失败不显示成功，检测到外部修订冲突时停止写入。旧笔记及旧历史缺少回顾字段时兼容默认值，周期与上次回顾时间写入 Markdown 元数据，随文件夹移动、备份和恢复保留；恢复内容历史不会抹掉已经确认的上次回顾时间。

## 5. 品交：展品与求品

品单社交以经过斟酌的表达和认真回应为方向。用户可以在完成本次梳理后主动选择分享，也可以一直私藏；编辑完成不自动引导发布。求品允许对方留出时间独立思考、稍后回应，不要求即时作答、同日完成或交换同等数量的条目。分享入口方便可达，但不打断正在进行的书写。

展品默认包含所有有效条目及理由，说明、标签、日期默认隐藏。用户可选择条目和开关字段，设置不修改原笔记。节选保留原排名，并标记“节选”。

展品和求品均提供“署名（选填）”，默认留空匿名，不自动带入任何个人身份。具名展品显示“某某的品单”，匿名显示“一份匿名品单”；具名求品显示“某某向你求品”，匿名显示“一位品友向你求品”。署名作为主题前的引导行，每页保留，长署名换行并相应下移主题与正文；不缩小字号，不写入原笔记。

图片形式默认“一张长图”，标题、条目与理由连续排版，保持字号；用户可切换“分页图片”，该模式尽量将一条完整留在同页，超长理由允许标记续页。长图只在首尾显示主题与页脚，不显示分页导航和页码；分页模式每页有主题、页码、品记署名和推广二维码区域。短内容生成紧凑图片。单张长图高度上限为 16000 像素，超过时提示切换分页，不截断、不自动替换用户选择的形式。两种品交图片均内置真实网页版二维码，指向 https://leoatopos.github.io/tistnote/ ，保留白色静区，不再显示占位文字。

预览与导出使用同一张生成结果。可以保存全部有序 PNG，也可以复制当前页到剪贴板。导出图片不携带未选择的字段、历史、设备或路径信息。

求品不要求已有答案。图片包含主题、可编辑邀请语、可选说明及网页版二维码；默认邀请语为“想知道你的答案：你会把哪些放进这份列表？”。禁止包含自己的条目、理由和历史，不要求对方身份。

首版不识别图片、不自动导入主题。二维码仅包含固定网页地址，不包含主题、答案、署名或设备信息，扫码打开品记网页版；二维码素材随应用内置，生成过程不联网。

## 6. 界面、资料库与隐私

左上角品记标志及名称为“关于品记”入口，打开六页介绍弹窗，每页一幅图和一句文案，支持左滑前进、右滑返回、上一页/下一页按钮及键盘左右方向键。前五页依次展示品牌、聊天中的女孩、病床上的老人、课堂中的男孩与女孩、夜晚书桌前的中年人；末页以 SVG 点线动画先写出标题，再逐项列出品单，提供“开始品记”按钮。六句文案与生成素材说明见 `src/Introduction.tsx` 和 `docs/INTRODUCTION_ART.md`。

已有品单首次在本机载入时自动介绍；空资料库不先打断选择，首次新建或打开品单时自动介绍。关闭或点“开始品记”后记录本机已读状态，之后不再自动弹出，点击品牌入口仍可重看。已读状态为本机界面偏好，不写入 Markdown 或资料库，不跨设备同步。插画和动画随应用本地打包，运行不联网；减少动态效果偏好下展示静态点线图。

主界面由导航、笔记列表、编辑区组成，入口为笔记、模板库、回收站及次要位置的设置。阅读、进入编辑和完成本次书写构成核心操作；品交在用户准备好表达时主动发起，“展品”和“求品”统一置于“品交”下拉菜单中，历史直接可访问。低频管理动作放入更多菜单。窄窗口收起侧栏或切换页面。

浅色中性色界面，以文字、留白和层级为主。重要操作使用文字，少量 SVG 辅助。无装饰性眉题、常驻宣传口号或解释性页脚，帮助由用户主动打开。

界面应支持半小时、一小时乃至更久的持续阅读、书写和回看：当前主题与正文优先，长内容通过合理宽度、换行与滚动呈现；分类管理、统计、模板探索和分享不得在编辑过程中主动弹出或抢占注意。郑重感来自内容受到认真对待、阅读舒适和保存可靠，不额外增设独立仪式页面、计时器或会话数据模型。

所有可阅读 UI 文字至少 18 CSS px，正文及状态默认 20px，主要标签和按钮 22–24px，包含弹窗、日期、差异、辅助文字。禁止通过缩放规避；空间不足时换行、重排或滚动。分享图片有独立可读基准，长内容分页。

首次启动创建或选择本地文件夹，一次打开一个资料库，可以切换。笔记为 UTF-8 Markdown，可用其他编辑器阅读与修改。历史、模板、回收站和管理数据在同一资料库的辅助目录，完整复制目录即可迁移。索引不得作为唯一数据来源。

提供文件管理器打开、完整备份、恢复到新文件夹和品记格式 Markdown 导入。任意 Markdown 自动转换不属于首版。文件名冲突与 Windows 非法字符不影响显示主题。

外部修改检测：重新进入应用或切回笔记时检查，无本地待保存修改时加载外部版本并记录；冲突时保留双方内容供用户选择，不能静默覆盖。解析失败保留原件并提示。写入采用完整性保护。

资源全部来自本机或安装包，不使用远程字体、脚本、图片、AI、遥测、远程错误上报。核心功能在断网环境可用，并提供离线安装方式。首版不加密资料库，不将访问密码作为必要能力。

## 7. 验收

断网完成首次使用、编辑、搜索、模板、历史、分享和备份恢复；重启内容一致；异常写入没有虚假的保存成功；历史恢复保留之前版本；求品不泄露答案；分享原排名与分页正确；长理由及中英混排不裁切；完整目录迁移可恢复所有数据。

检查实际渲染字号、桌面与移动端宽度截图。窄屏检查不代表首版推出移动客户端。需要覆盖文件冲突、损坏、无写入权限和磁盘写满场景，正式二维码占位能在发布时替换。

补充梳理书写场景验收：覆盖多条目、长理由、持续修改、撤销重做、排序及自动保存交错的使用，检查内容、输入焦点与编辑位置保持合理稳定；中途离开后能找回已保存内容，完成编辑后可重读并比较版本。覆盖重要经历后重读旧品单、正式修订、按需命名里程碑及选择分享的完整流程。长时间体验检查关注阅读舒适、操作干扰和数据可靠性，不要求用户必须写满半小时或一小时，也不新增使用时长采集。

首版完成标准：用户能在离线环境中，围绕一个主题沉下心来梳理和书写自己的品单，在重要经历后郑重修订，可靠保存并重读判断的持续与变化；准备好交流时，再生成清晰且自行控制公开范围的图片与他人交换答案。验收不以首条录入速度、单次条目数量或每天打开次数代替上述体验。
