# 品记 tistnote｜产品需求文档 v1.0

状态：用户确认，首版实施基线。2026-10-21。

## 1. 产品定位

品记（tistnote，taste list note）是一款完全离线、以列表记录个人审美与偏好的笔记应用。核心定位是品察世间万物与人生百态：喜欢、欣赏、认同，以及不喜欢、讨厌、反感与分歧都可以记录，也容纳复杂、矛盾和尚未确定的感受。每一份列表都可以留下个人的感受、判断及其缘由。

随着技术发展，人的价值将越来越多地体现在独特的感受、选择、表达与创造之中。审美既存在于电影、文学和哲学，也存在于旅行、饮食、牙刷等日常选择。品记把对世间人生的观察、好恶与思考，变成可以积累、回看与交流的记录。

核心价值：用列表认识自己，用变化理解自己，用分享认识彼此。

核心问题：我喜欢什么、讨厌什么，认同什么、反感什么，为什么；如何表达和排列自己的感受与判断；我的审美与偏好如何变化；我希望别人了解我的什么，又希望了解对方什么。

首版面向品察日常与人生、梳理个人好恶、记录审美与偏好变化、与朋友交流感受的人群。采用 Tauri 开发 Windows 10/11 x64 版本，控制包体。

全部笔记、模板、历史、图片生成均在本地完成。没有账号、服务器、云同步、在线模板库、信息流、社交关系、广告、遥测、联网分析或联网更新。分享仅生成图片，不生成可浏览的笔记链接。导出和备份属于数据管理。

## 2. 数据与流程

笔记由主题、可选说明、多个标签、排名模式、条目、时间与版本历史组成。条目包含名称、可选理由和稳定身份。模板来源可记录，但笔记创建后独立于模板。

有排名与无排名随时切换，保留条目与顺序；无排名的顺序仅表示展示位置。首版使用纯文字，不包含图片条目、星级评分、嵌套列表、复杂表格或富文本。

主流程：

1. 新建或从模板开始 → 填写 → 排序与补充理由 → 自动保存。
2. 浏览、搜索或按标签随机抽取模板 → 确认主题 → 创建笔记。
3. 打开历史 → 比较两个版本 → 按需恢复。
4. 分享 → 选择条目与公开字段 → 预览 → 保存 PNG → 用户自行发送。
5. 求分享 → 确认主题与邀请语 → 保存图片 → 对方自行填写同主题列表并以图片回应。

应用不追踪邀请发送、填写或回应，不记录收件人身份。

## 3. 笔记与模板

- 支持笔记新建、重命名、复制、删除、恢复、永久删除。复制不携带历史。
- 2026-10-24 调整：笔记列表默认精简展示，仅显示标题；无有效条目时在标题同行显示“（空）”，可切换为详细展示。搜索与标签筛选默认收起到按钮中，启用条件后保留状态并可清除。
- 2026-10-24 精简工具区：标题与查找、更多、新建三个图标入口同行，下方直接展示文件树。查找按需展开搜索和标签，收起后用状态圆点标明仍在筛选；更多菜单承载排序、展示模式、全部展开 / 折叠、分组管理、笔记数量与新建位置，支持返回根目录。点击外部或按 Esc 关闭菜单，Esc 将焦点返回入口。
- 2026-10-24 调整：同一资料库的在用笔记标题不得重复，比较时忽略首尾空白，其余按原文精确比较。新建笔记（包括从模板创建）自动选择未占用的标题：原名可用则用原名，否则依次尝试“原名（1）”“原名（2）”等，跨分组检查，不因默认标题重名阻止新建。手动改名、导入与恢复发生重名时仍弹窗提示，保留原记录；复制继续自动选择未占用的副本序号。既有同名笔记提示用户改名，不合并、不删除，仍允许保存正文。
- 自动保存显示真实状态，失败保留编辑内容并允许重试。
- 2026-10-24 调整：打开已有笔记、切换笔记及重新启动默认进入浏览状态，仅用文字列表展示标题、可选说明、有效条目与理由，不显示输入框、空字段占位、分组 / 标签编辑、拖动排序、增删和撤销控件。点击“编辑”后显示原编辑界面；“完成编辑”先保存并补记历史，成功后返回浏览，失败保留当前编辑与草稿。新建笔记直接进入编辑。浏览时保留编辑与分享入口，历史和求分享放入更多菜单。
- 2026-10-24 启动页调整：恢复上次资料库、创建或切换资料库时，竖屏 / 窄屏默认进入“我的笔记”列表，不直接跳到最近笔记内容；点选笔记才进入浏览，可返回列表。宽屏横向窗口仍保留列表与内容双栏，新建笔记仍直接进入编辑。
- 空资料库例外：没有在用笔记时，竖屏 / 窄屏的笔记区域显示“从一次品察开始”引导，提供“写一份新笔记”和“去模板库找灵感”。创建首篇后重新打开进入列表，删除最后一篇后回到空资料库引导；有笔记的资料库继续遵循列表优先规则。
- 条目支持新增、修改、删除、拖动、上下移动及键盘排序；Enter 连续录入。
- 支持撤销 / 重做；按最近修改、创建时间、主题排序。
- 搜索主题、说明、条目、理由、标签；多标签默认任一匹配，可结合搜索。
- 2026-10-24 调整：支持新建、重命名、删除空分组及移动笔记。分组对应 `notes/` 下的实际文件夹，支持子分组；未分组笔记直接位于 `notes/`。笔记列表使用类似文件管理器的树状结构，直接展示文件夹、子分组及所属笔记，根层级显示未分组笔记。支持单个及全部展开 / 折叠、方向键导航，搜索和标签筛选保留匹配笔记的上级路径。点击文件夹后，新笔记直接存入该目录；选择“根目录”后在根目录新建。标题唯一性仍覆盖整个资料库，不能通过切换分组绕过。
- 标签用于跨分组分类。分组改名同时更新子分组路径，移动不改写 Markdown 正文或版本历史；删除非空分组会提示先移出笔记、删除子分组。回收站保留原分组路径，恢复时原分组不存在则放回未分组。资料库备份包含全部分组和空文件夹。
- 2026-10-24 调整：在“我的笔记”文件树中，可将笔记拖到其他文件夹，或将文件夹连同子目录与笔记拖到其他文件夹；拖拽期间显示“移到根目录”区域并高亮有效目标，支持 Esc 取消。移动先保存当前编辑，完成后展开目标路径，保留当前阅读 / 编辑状态。禁止将文件夹移入自身或子目录；同名文件夹提示冲突，不覆盖或合并。按用户选择，仅移动目录归属，不增加同目录内的手动上下排序。
- 空白笔记使用“未命名笔记”，已有同名笔记时自动加括号数字。带编号的未命名标题仍属于草稿，分享或提取模板前要求填写主题；空白草稿不因编号生成初始内容历史。
- 空白条目不计数、不出现在分享图；空列表只能求分享。
- 删除进入本地回收站，历史一起保留；永久删除必须确认。
- 2026-10-24 调整：回收站入口放在“设置”的本地资料库操作中，侧栏只保留笔记、模板库和历史。未打开资料库时回收站入口禁用，原有恢复、重名保护与永久删除确认保持不变。

模板包含主题、可选说明与填写提示、标签、默认排名模式、建议条目数。建议数量不限制填写数量。

首版提供约 45 个内置主题，覆盖电影、文学、音乐、旅行、饮食、生活用品、思想与哲学、休闲、设计及人与关系。内置主题兼顾喜欢与欣赏、不喜欢与反感，以及复杂和未定的感受。原有主题 ID 保持稳定，补充的负向与中性主题追加在目录末尾。内置模板不可直接修改，可以复制后编辑。

用户可以新建、编辑、复制、删除个人模板，也可以从笔记提取主题、说明、标签与模式。提取时不复制答案和理由，保存前展示可编辑预览。

2026-10-24 模板覆盖率：模板卡片与随机抽到的主题在已有对应品记时显示“有品”，侧栏“模板库”旁显示整个模板库的覆盖百分比，页面显示有品数量 / 模板总数。范围包括内置及个人模板，搜索和标签筛选不改变总分母；同一模板最多计一次，百分比保留一位小数。对应品记按模板来源 ID 或标题完全一致（忽略首尾空白）识别，须有有效主题及至少一个非空条目；空笔记、空白条目和回收站笔记不计入。带来源的笔记改名后仍保留关联，清空 / 删除 / 恢复后按在用笔记实时更新；覆盖状态由已有数据计算，不新增追踪日志。

随机抽取遵循当前搜索和标签条件，多个候选时不连续重复；换题不会创建笔记，只有点击“开始填写”才创建。模板后续修改和删除不影响既有笔记。标签清理首尾空白并去重。

## 4. 版本日志

2026-10-24 新增使用历史：侧栏在“模板库”下方提供独立“历史”入口，以类似 GitHub contribution graph 的年度日期网格展示新增与修改活跃度。支持切换年份、选择日期、键盘方向键导航、查看当天记录及打开仍在用的笔记。窄屏图表内部横向滚动，不缩小文字。创建按笔记创建时间统计，修改按保存版本的实际内容变化及修改时间汇总；同一天同一篇笔记的多次修改合并计一次。未改内容的里程碑、重复打开和刷新不增加次数，跨天才首次填写空白笔记会计入填写当天的修改。

汇总完全读取本地现有笔记、回收站和版本文件，不联网，不单独追踪使用行为，不改写原文件。早期记录以已保留版本为准，无法还原未保存成版本的中间编辑；永久删除笔记及其历史后，其记录也从使用历史移除。原有单篇笔记版本比较与恢复仍保留在笔记界面。

自动保存与版本记录独立：前者保护当前内容，后者形成可阅读的时间线。

- 首次有效内容创建初始版本。
- 有修改且停止编辑 60 秒后生成自动版本。
- 离开笔记或正常关闭应用时补存尚未记录的内容。
- 相同内容不重复创建自动版本。
- 手动里程碑可以命名；首版不自动清理历史。
- 时间线显示时间、类型、名称和变化摘要。
- 默认比较所选版本与前一版本，也支持任选两个版本。
- 比较条目增删、改名、理由、位置 / 排名及主题、说明、标签和模式。
- 稳定条目标识避免将改名误判为增删；标识丢失时明确提示精度下降。
- 恢复前留存当前内容，恢复形成新版本，不修改旧历史。
- 异常退出后以最后成功保存内容恢复；重新打开时补记遗漏版本。

## 5. 分享与求分享

答案分享默认包含所有有效条目及理由，说明、标签、日期默认隐藏。用户可选择条目和开关字段，设置不修改原笔记。节选保留原排名，并标记“节选”。

内容超出单页时自动分页，不能缩小字号。尽量将一条完整留在同页，超长理由允许标记续页。每页有主题、页码、品记署名和推广二维码区域。短内容生成紧凑图片。二维码未提供时明确标记“下载二维码预留”，不得使用虚假二维码。

预览与导出使用同一张生成结果。可以保存全部有序 PNG，也可以复制当前页到剪贴板。导出图片不携带未选择的字段、历史、设备或路径信息。

求分享不要求已有答案。图片包含主题、可编辑邀请语、可选说明及推广二维码占位；默认邀请语为“想知道你的答案：你会把哪些放进这份列表？”。禁止包含自己的条目、理由和历史，不要求对方身份。

首版不识别图片、不自动导入主题。正式二维码仅引导下载安装，随安装包内置；生成过程不联网。

## 6. 界面、资料库与隐私

主界面由导航、笔记列表、编辑区组成，入口为笔记、模板库、回收站及次要位置的设置。分享与求分享是主要操作，历史直接可访问，低频动作放入更多菜单。窄窗口收起侧栏或切换页面。

浅色中性色界面，以文字、留白和层级为主。重要操作使用文字，少量 SVG 辅助。无装饰性眉题、常驻宣传口号或解释性页脚，帮助由用户主动打开。

所有可阅读 UI 文字至少 18 CSS px，正文及状态默认 20px，主要标签和按钮 22–24px，包含弹窗、日期、差异、辅助文字。禁止通过缩放规避；空间不足时换行、重排或滚动。分享图片有独立可读基准，长内容分页。

首次启动创建或选择本地文件夹，一次打开一个资料库，可以切换。笔记为 UTF-8 Markdown，可用其他编辑器阅读与修改。历史、模板、回收站和管理数据在同一资料库的辅助目录，完整复制目录即可迁移。索引不得作为唯一数据来源。

提供文件管理器打开、完整备份、恢复到新文件夹和品记格式 Markdown 导入。任意 Markdown 自动转换不属于首版。文件名冲突与 Windows 非法字符不影响显示主题。

外部修改检测：重新进入应用或切回笔记时检查，无本地待保存修改时加载外部版本并记录；冲突时保留双方内容供用户选择，不能静默覆盖。解析失败保留原件并提示。写入采用完整性保护。

资源全部来自本机或安装包，不使用远程字体、脚本、图片、AI、遥测、远程错误上报。核心功能在断网环境可用，并提供离线安装方式。首版不加密资料库，不将访问密码作为必要能力。

## 7. 验收

断网完成首次使用、编辑、搜索、模板、历史、分享和备份恢复；重启内容一致；异常写入没有虚假的保存成功；历史恢复保留之前版本；求分享不泄露答案；分享原排名与分页正确；长理由及中英混排不裁切；完整目录迁移可恢复所有数据。

检查实际渲染字号、桌面与移动端宽度截图。窄屏检查不代表首版推出移动客户端。需要覆盖文件冲突、损坏、无写入权限和磁盘写满场景，正式二维码占位能在发布时替换。

首版完成标准：用户能在离线环境中，从一个主题开始形成自己的 taste list，可靠保存和回看变化，并生成清晰且自行控制公开范围的图片与他人交换答案。
